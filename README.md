# ToDoアプリ

JavaScriptやWeb開発の学習をしながら作成したToDoアプリです。

HTML・CSS・JavaScriptを使って、タスク管理ができるようにしました。
最初はシンプルな追加機能だけでしたが、学習を進めながら機能を少しずつ増やしました。

## 使用技術

- HTML
- CSS
- JavaScript

## 実装した機能

- タスク追加
- Enterキーで追加
- 編集機能
- 削除機能
- 完了チェック機能
- 完了タスク表示
- 完了日時表示
- ダークモード切り替え
- localStorage保存
- レスポンシブ対応

## 工夫したところ

localStorageを利用して、ページを更新してもタスクが消えないようにしました。

また、ダークモード機能やレスポンシブ対応も追加し、使いやすいデザインを意識しました。

## 今後追加したい機能

- Firebaseを使ったデータ保存
- ログイン機能
- タスクの優先度設定

このアプリ制作を通して、

などを学ぶことができました。
