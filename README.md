# ToDoアプリ

JavaScriptやWeb開発の学習をしながら作成したToDoアプリです。

HTML・CSS・JavaScriptを使って、タスク管理ができるようにしました。
最初はシンプルな追加機能だけでしたが、学習を進めながら機能を少しずつ増やしました。

## 使用技術

- HTML
- CSS
- JavaScript
- Firebase Authentication
- Firebase Firestore

## 実装した機能

- タスク追加
- Enterキーで追加
- 編集機能
- 削除機能
- 完了チェック機能
- 完了タスク表示
- 完了日時表示
- ダークモード切り替え
- Firestoreデータ保存
- Googleログイン / ログアウト
- ユーザー別タスク管理
- レスポンシブ対応

## 工夫したところ

Firestoreを利用して、ページを更新してもタスクが消えないようにしました。

また、Googleログイン機能を追加し、ユーザーごとにタスクを管理できるようにしました。

さらに、ダークモード機能やレスポンシブ対応も追加し、スマートフォンでも使いやすいデザインを意識しました。


## 今後追加したい機能

- プロフィール画像表示
- カレンダー表示
